## Position

One commit, ed6a0bd on `presence-connected`, rebased on main 8a7e6ef. Not merged.

- Coordinator (`src/coordinator.rs`): `connected: HashSet<Address>`, memory only. Register sets it, and that includes a daemon's re-registration after it reconnects. A daemon's `disconnect` clears it, but only when the Address is still on that host. A `HostLink` drop guard clears it for every session of a host when that host's link ends, by EOF, by error, or by an early `?`, and only if the connection still owns the host slot. Each of these is stamped into `seen`. The Board row carries `connected`. `last_seen_ms` is the read time while connected, else `seen`. An ack with `replay: true` does not touch `seen`.
- Host daemon (`src/daemon.rs`): when a session's local connection closes, the daemon sends `{"type":"disconnect","session"}` upstream. It does this only if that connection is still the session's registered writer (`Arc::ptr_eq`), and it no longer removes a newer registration. It marks replayed receipts `replay: true`.
- Client: the SESSION line is `address= host= connected= last_seen_ms= label=`.
- Shim (`shims/pi/roger-command.ts`): the default view is `connected || seen within ROGER_PRESENCE_WINDOW_MS`. Connected rows read `— connected`.
- Tests: `presence_is_the_open_session_connection_then_own_activity`, `host_link_drop_disconnects_its_sessions_and_reregistration_restores_them`, `a_replayed_ack_is_not_activity`. The `pi-shim` acceptance gains an idle-past-a-1s-window section.
